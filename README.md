# PayFlow AI

PayFlow AI is an AI-assisted invoicing application built with Angular and FastAPI, designed to integrate with PayPal Sandbox for invoice creation and payment tracking.

## Project structure

- `frontend/`: Angular user interface
- `backend/`: FastAPI API, invoice records, AI draft generation, and PayPal Sandbox integration

## Development status

**Work in progress.** The full application source, backend hosting, and sandbox configuration have not yet been published or completed. Do not treat this repository as a running production application.

## Security

PayPal client secrets, API keys, and database credentials must be configured as deployment secrets and must not be committed to this repository.
